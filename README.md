# C# + React Application

This project features a decoupled architecture containing a C# (ASP.NET Core) Web API backend and a React (Vite) frontend.

---

## 🛠️ Prerequisites

Ensure you have the following installed locally:
* **.NET 8.0 SDK** (or later)
* **Node.js** (LTS version)

---

## ⚙️ Environment Configuration

This project uses dynamic environment variables to avoid hardcoded URLs, allowing seamless switches between local development and production.

### 1. Frontend Configuration (React)
1. Navigate to the `frontend/` folder.
2. Create a local environment file named `.env` (this file is excluded from git tracking).
3. Add the following key matching your backend port:
   ```env
   VITE_API_URL=http://localhost:5070
   ```

### 2. Backend Configuration (C#)
1. Navigate to the `backend/` folder.
2. Open `appsettings.json` and ensure your frontend origin is mapped dynamically:
   ```json
   {
     "AllowedOrigins": {
       "ReactApp": "http://localhost:5173"
     }
   }
   ```

---

## 🚀 Local Setup Instructions

Follow these steps to run both applications simultaneously.

### 1. Start the Backend (C# API)
1. Open a new terminal and navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Run the development server:
   ```bash
   dotnet run
   ```
3. **Verification URL:** Open `http://localhost:5070/weatherforecast` in your browser to confirm the API endpoints are active.

### 2. Start the Frontend (React)
1. Open a **second** terminal window and navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies (first time only):
   ```bash
   npm install
   ```
3. Run the frontend development server:
   ```bash
   npm run dev
   ```
4. **Verification URL:** Open `http://localhost:5173` in your browser.

## 🧪 Testing the Connection

The project includes a pre-configured connection test to verify full-stack integration:

1. Adjust `.env` and  `appsettings.json` to match your currently running ports.
2. **Success State:** If successful, the boilerplate weather dataset generated by the C# controller will automatically map out into a list on the React homepage.

## 📁 Project Architecture

```text
MyFullStackApp/
├── backend/          # C# ASP.NET Core Web API (Business logic & database)
│   ├── Controllers/  # API Endpoint routes
│   ├── appsettings.json # App configurations (CORS URLs, DB Strings)
│   └── Program.cs    # Application bootstrap & configuration loader
└── frontend/         # React + Vite (User Interface)
    ├── .env          # Local environment variables (GIT IGNORED)
    ├── src/          # React components
    └── package.json  # Node dependencies
```

---

## ⚠️ Security Rules
* **Never place secrets in React.** Frontend variables are compiled into public JavaScript. Keep all database strings and private API keys securely inside `backend/appsettings.json`.
