# C# + React Application

This project features a decoupled architecture containing a C# (ASP.NET Core) Web API backend and a React (Vite) frontend.

---

## 🛠️ Prerequisites

Ensure you have the following installed locally:
* **.NET 8.0 SDK** (or later)
* **Node.js** (LTS version)

---

## 🚀 Local Setup Instructions

Follow these steps to run both applications simultaneously.

### 1. Start the Backend (C# API)
1. Open a new terminal.
2. Navigate to the backend directory:
   ```bash
   cd backend
   ```
3. Run the development server:
   ```bash
   dotnet run
   ```
4. **Verification URL:** Open `http://localhost:5070/weatherforecast` in your browser to confirm the API endpoints are active. *(Note: Check console output if your port differs).*

### 2. Start the Frontend (React)
1. Open a **second** terminal window.
2. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
3. Install dependencies (first time only):
   ```bash
   npm install
   ```
4. Run the frontend development server:
   ```bash
   npm run dev
   ```
5. **Verification URL:** Open `http://localhost:5173` in your browser.

---

## 🧪 Testing the Connection

The project includes a pre-configured connection test to verify full-stack integration:

1. **CORS Configuration:** `backend/Program.cs` is configured to whitelist requests originating from `http://localhost:5173`.
2. **Data Fetching:** `frontend/src/App.jsx` automatically uses the native browser `fetch()` API to target the backend `http://localhost:5070` data stream.
3. **Success State:** If successful, the boilerplate weather dataset generated by the C# controller will automatically map out into a list on the React homepage.

